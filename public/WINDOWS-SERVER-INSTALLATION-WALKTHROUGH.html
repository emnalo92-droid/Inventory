Candy Store & Takehome Inventory

Windows Host Server & Local Cashier Network Installation Walkthrough

System Administration & In-Store Terminal Deployment Manual

1. Executive Summary & Architecture

This application is designed to run directly on your store's Windows computer (acting as the Host Server). Any computer, laptop, tablet, or smartphone connected to the same in-store Wi-Fi or LAN can access the system via web browser or standalone desktop window.

Component Specification / Details
Operating System Windows 10 or Windows 11 (64-bit)
Runtime Node.js 18 LTS or Node.js 20+ LTS (Free from nodejs.org)
Server Port 3000 (Binds to 0.0.0.0 for local network listening)
Network Requirement Local Area Network (Wi-Fi router or Ethernet switch)
Cashier Clients Google Chrome, Microsoft Edge, Safari (iPad/iPhone), or Firefox
Key Benefit: All branch inventories, shift reconcile records, and cashier logs entered across different devices sync in real time directly to your host computer.

2. Step-by-Step Installation Walkthrough

Step 1: Install Node.js on the Host Computer

  1. Open your browser and visit: https://nodejs.org/
  2. Download the LTS (Recommended For Most Users) Windows installer (.msi).
  3. Double-click the downloaded file and follow the standard installation wizard:
    • Accept the License Agreement.
    • Keep the default installation path (C:\Program Files\nodejs\).
    • Leave all standard features checked.
    • Click Install and then Finish.
  4. Verification: Open Command Prompt and type node -v. It should print a version like v18.x.x or v20.x.x.

Step 2: Place Application Files on Your Computer

  1. Extract or copy the project folder to a permanent location on your PC (for example: C:\CandyStoreApp\ or D:\CandyStoreApp\).
  2. Ensure the three one-click Windows launcher scripts exist inside the folder:
    • setup-windows.bat — First-time setup & desktop shortcuts
    • start-windows-server.bat — Main server launcher with IP detection
    • launch-desktop-app.bat — Standalone borderless desktop window

Step 3: Run the 1-Click Setup Wizard

  1. Double-click setup-windows.bat.
  2. The wizard will automatically perform three operations:
    • [1/3] Install required packages (npm install).
    • [2/3] Compile and build optimized production assets (npm run build).
    • [3/3] Create two shortcuts directly on your Windows Desktop:
      • "Candy Store Host Server"
      • "Candy Store Desktop App"
  3. Press any key when the setup displays SETUP COMPLETE!.

Step 4: Configure Windows Defender Firewall (One-Time)

By default, Windows Firewall protects your computer by blocking incoming network traffic on unfamiliar ports. You must allow Port 3000 so cashiers on other devices can connect:

  1. Right-click the Windows Start menu button.
  2. Select Terminal (Admin) or Command Prompt (Run as Administrator).
  3. Paste the following command and press Enter:
netsh advfirewall firewall add rule name="CandyStoreServer" dir=in action=allow protocol=TCP localport=3000
Result: Windows will print Ok. Port 3000 is now open for devices on your local store Wi-Fi network!

Step 5: Start the Host Server

  1. Double-click the "Candy Store Host Server" shortcut on your Desktop (or run start-windows-server.bat).
  2. The server console will open in a green command window:
    • It confirms Node.js is ready.
    • It discovers and displays your computer's local Wi-Fi / LAN IP addresses.
    • It prints your Computer Name URL (e.g. http://STORE-PC:3000).
    • It automatically launches the app window on your screen!
Important: Keep this server command window open (or minimized) while the store is operating. If you close this window, the server stops.

3. What to Do If Your IP Address is Automatically Obtained (DHCP)

If your network router assigns IP addresses automatically, your numeric IP (e.g. 192.168.1.15) might change whenever the computer or router restarts. Choose one of these solutions:

Solution A: Use the Computer Name URL (Recommended — Zero Configuration)

Windows computers broadcast their machine name across the local network. You do not need numbers!

  • On Windows cashier PCs/laptops, open browser and navigate to:
    http://<YOUR-COMPUTER-NAME>:3000
    Example: http://STORE-SERVER:3000
  • On iPads, iPhones, Macs, or Android devices, navigate to:
    http://<your-computer-name>.local:3000
    Example: http://store-server.local:3000
Why this works: Even when the router gives your computer a new IP address, the Computer Name URL stays 100% constant forever.

Solution B: Lock a Fixed (Static) IP in Windows Settings (1 Minute)

  1. Press Win + R, type cmd, press Enter, and run ipconfig to see your current IP, Subnet Mask, and Default Gateway.
  2. Open Windows Settings (Win + I) → Network & internet → Wi-Fi (or Ethernet).
  3. Click on your connected network properties.
  4. Under IP assignment, click Edit and select Manual.
  5. Turn on IPv4 and enter:
    • IP address: 192.168.1.100 (or your current IP)
    • Subnet prefix length: 24 (equivalent to mask 255.255.255.0)
    • Gateway: 192.168.1.1 (your router IP)
    • Preferred DNS: 8.8.8.8 (Google DNS)
  6. Click Save. Your server will now permanently hold this exact IP.

Solution C: Router DHCP Reservation

Log in to your Wi-Fi router admin panel (usually http://192.168.1.1), open DHCP Settings → Address Reservation, and bind your computer's MAC address to a permanent IP.

4. Connecting Cashier Terminals & Branch Devices

  1. Ensure the cashier device (tablet, phone, or laptop) is connected to the same store Wi-Fi network as the host computer.
  2. Open Google Chrome, Microsoft Edge, or Safari on the cashier device.
  3. Type the Host URL: 
    http://<COMPUTER-NAME>:3000   OR   http://192.168.1.100:3000
  4. Bookmark the page or tap "Add to Home Screen" / "Install App".
  5. The cashier can log in with their assigned username and begin recording AM/PM shift inventory and cash reconciliations.

5. Running in Standalone Desktop Application Window Mode

You do not need to use a standard web browser with tabs and URL bars:

  1. Double-click launch-desktop-app.bat (or the Desktop shortcut "Candy Store Desktop App").
  2. This launches Microsoft Edge or Chrome in Chromium Application Mode (--app=http://localhost:3000 --window-size=1400,900).
  3. The app displays in a sleek, borderless window with its own taskbar icon, maximizing screen real estate for store operations.

6. Optional: Auto-Start Server When Computer Powers On

  1. Press Windows Key + R on your keyboard.
  2. Type shell:startup and click OK. This opens your personal Windows Startup folder.
  3. Right-click inside the folder → New → Shortcut.
  4. Browse to your project folder and select start-windows-server.bat.
  5. Click Next and Finish.
  6. Now, whenever you power on or restart your computer, the server starts automatically in the background!

7. Troubleshooting & Frequently Asked Questions

Issue Cause & Solution
Cashier device says "Site cannot be reached" 1. Ensure both devices are on the exact same Wi-Fi network.
2. Verify Windows Defender Firewall rule was added (see Step 4).
3. Confirm the green server window is running on the host computer.
"Port 3000 already in use" error An existing instance of the server is already running. Open Task Manager (Ctrl + Shift + Esc), look for Node.js under Processes, end the task, and double-click start-windows-server.bat again.
IP address changed after router rebooted Use the Computer Name URL (http://<COMPUTER-NAME>:3000) or follow Solution B above to set a static IP in Windows Settings.
